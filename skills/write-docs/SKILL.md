# Write docs

- Lead with what it is and the one command to try it.
- Every instruction is copy-pasteable and was run by you.
- Explain why for anything surprising; skip what the code already says.
- Show the real output a user will see, including errors and how to fix them.
- Keep claims honest: no "blazing fast" without a number, no feature that is not shipped.
- Comments explain intent and constraints, not syntax. Update or delete stale ones.
