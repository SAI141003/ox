# Brainstorm a design

1. Ask who it is for and what they do today without it. One question at a time.
2. Name the single outcome that makes this worth building.
3. Offer 2-3 approaches with honest trade-offs (effort, risk, what each rules out). Recommend one.
4. Cut scope: list what the first version will NOT do.
5. Write the design in under a page: purpose, user flow, data, components, how it will be tested.
6. Get a yes before writing code. Then hand off to plan-first.
