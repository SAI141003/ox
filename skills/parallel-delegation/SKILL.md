# Parallel delegation

1. Split only truly independent work: no shared files being edited, no ordering between parts.
2. Give each subagent a self-contained brief: goal, files, constraints, what "done" looks like, what to return.
3. Ask for conclusions, not transcripts: a short report with file:line evidence.
4. Launch independent subagents in the same turn so they run concurrently.
5. Review every result before acting on it; a subagent's claim is a lead, not proof.
6. Integrate yourself and run the full checks once at the end.

Do not delegate one-step work; the brief costs more than doing it.
