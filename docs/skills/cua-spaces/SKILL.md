# CUA Spaces in Ox

Treat a CUA Space as a distinct runtime only after CUA reports a selected,
active Space. A workspace directory, application profile, or session label is
not a separate computer. Record the Space identity, access grant, and intended
workspace before delegating work there.

Keep credentials in the Space's approved secret mechanism, preserve Ox's
approval gates for external effects, and verify results in the chosen Space.
When it is stopped or unavailable, report the condition and choose an
explicitly approved fallback; do not silently move work to another machine.

This is an Ox-owned safe adaptation of the upstream CUA Spaces guidance.
Install and authenticate CUA through its verified upstream instructions rather
than executing an unreviewed remote installer.
