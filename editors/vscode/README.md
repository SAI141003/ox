# ox for VS Code

The ox agent beside your code, in VS Code, Cursor, Windsurf and other forks.

- **ox: Open chat** (`Cmd+Alt+O`): the app's chat in a side panel.
- **ox: Ask about the selection**: your question and the selected code go to ox in the terminal.
- **ox: Fix the problems in this file**: the file's errors and warnings go to ox.
- **ox: Start in the terminal**.

Install ox first. To install this extension from the repo: `npx @vscode/vsce package`, then
**Extensions › … › Install from VSIX**. It isn't on the Marketplace yet.
