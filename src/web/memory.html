① Write: when you say something

Each new statement is checked against what ox already knows: a new fact is added, a change replaces the old one (kept as history), a repeat makes it stronger.

② Read: before every run

Only a short profile and the few memories that match the task go to the model, never your whole history.

–

③ Vault: what is kept

Stored on this Mac as plain lines you can read. Nothing is deleted: old versions and faded facts stay, out of the way.

④ Sleep: while you are away

Merges duplicates, retires past events, strengthens what keeps being used, lets unused facts fade, and turns lessons that worked twice into procedures.

How one message flows
  1. You say “I prefer pnpm”. The write desk finds no older package-manager fact, so it files a new preference card in the vault.
  2. Later you say “I use bun now”. Same slot, new value: the new card replaces the old one, which moves to history with the date it stopped being true.
  3. You ask ox to install dependencies. The read desk takes your profile plus the matching card (bun) to the model, a few hundred tokens instead of every past chat.
  4. At night the sleep room notes the bun card was used, so it gets stronger and stays near the top.
